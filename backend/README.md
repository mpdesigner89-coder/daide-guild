# Backend — vùng phát triển

Thư mục này được để sẵn làm ranh giới cho API server; hiện chưa có server chạy được và chưa kết nối database.

Đề xuất bắt đầu bằng Node.js + Express/Fastify, PostgreSQL, migration và test. Xem `../docs/BACKEND-ROADMAP.md` để biết miền dữ liệu, API và yêu cầu bảo mật. Khi triển khai thật, backend phải là nguồn dữ liệu chuẩn; không tin dữ liệu lương/giá đấu do client gửi lên.
